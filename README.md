## قابلیت‌ها

- سه موتور: Xray، Tor (با پل WebTunnel) و WARP
- دریافت و تست خودکار کانفیگ‌های عمومی (vless/trojan با TLS و Reality)
- گزینه فرگمنت (Fragment) برای عبور از DPI، پیش‌فرض خاموش
- رابط فارسی و راست‌به‌چپ
